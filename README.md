# Animación de 3 etapas con Remotion

Esta composición (`CircleJourney`) muestra el proceso solicitado en tres fases:

1. **Training**: dos círculos separados (`me` y `other`).
2. **Mentoring**: el círculo `me` crece y se vuelve ovalado para cubrir `other`.
3. **Coaching**: `other` queda dentro de `me`.

## Ejecutar en local

```bash
npm install
npm run start
```

## Renderizar video

```bash
npm run build
```

El render sale en `out/video.mp4`.
